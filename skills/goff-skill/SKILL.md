# goff skill

用户明确要求查看提示词原文时，先读取对应方式的文件并贴出引文。若用户要看全部原文，按 goff-1 至 goff-4 的顺序贴出。

打开总入口后，展示下列四项并等待选择。用户已经明确选了方式时，直接处理。保留用户随调用提供的任务，选定后继续。

1. **goff-1 · 第一性原理** · 找出真正要解决的问题。
2. **goff-2 · 先问再做** · 对齐偏好，再给三版方案。
3. **goff-3 · 跨领域借鉴** · 看其他领域如何解决同类问题。
4. **goff-4 · 反方检验** · 找能推翻现有方案的证据、反例和边界。

当前聊天的选择控件能在一题内显示四个选项时，用一题显示四项，并请用户单选或填写组合。否则显示编号菜单，接受 `goff-1`、`第一性原理`、`1` 等单选，也接受 `goff-1+goff-4`、`1+4` 或 `1、4` 等组合。

执行已选方式或查看提示词原文时，从本 Skill 目录的上一级读取同级的方式文件，例如 `../goff-1/SKILL.md`。按选定顺序各执行一次。缺少任务时，承接本聊天里指向明确的问题或方案。没有明确对象时，只问要处理哪个问题或方案。选项有歧义时，只确认有歧义的部分。

组合含 goff-2 时，先问会影响方案的未知偏好，等用户回答再给三版。其他方式得到的发现可写入三版方案和取舍说明。
