# 恢复已确定归属的可见边缘

完全不透明且可确认归属的像素直接使用原图 RGB。对不透明物件的半透明轮廓，原图颜色已经混合了后景。先在当前工作 PSD 中只开启目标物体以下的图层，原位导出一张承接底色 PNG。用灰度图标出当前实际可见、没有上层投影或其他物件影响且归属已经确认的边缘。灰度图白色表示参与求解，黑色保留原件。物体藏在碗或桌下的部分应为黑色。

对「正常」混合、普通不透明度、同色域工作稿，可运行以下命令。需要 Pillow 和 NumPy，候选与底色要在同一像素网格上。

```sh
python3 scripts/fit_visible_edge.py 原稿.jpg 完整素材.png 承接底色.png 可见归属.png 修边候选.png
```

它固定物件覆盖度和遮挡下的原件，在白区内寻找能重现原图的直通 RGB 值，优先选接近原素材的解。若使用 PSD 灰度蒙版，传入图层与当前蒙版相乘后的有效 alpha，回写时只取颜色通道，保留原始素材 alpha 与 PSD 蒙版。计算以 Pillow 的正常合成为候选，最终以 Photoshop 实际导出为准。默认每通道最多偏移 48 级，以限制错误归属引起的异色。可按已知材质收紧或显式指定 `--max-change`。退出码 1 表示仍有无解像素，脚本保留它们原来的值并保存其余结果。回查蒙版、阴影和承接底色。不能把大幅估错的底色硬塞进半透明边缘。分别在深浅底上查看颜色和轮廓后，再决定是否采用。
