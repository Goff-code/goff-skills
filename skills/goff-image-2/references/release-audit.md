# 二代验收

把最终源文件保存并关闭，按本次清单用 Photoshop 从磁盘重开，导出全开图及各项无损 PNG 校样。保留原位完整素材、坐标、蒙版、图层 JSON 与校样 JSON。目录可整体移动。

为当前画面写一份验收表。下例有后排包装、前排商品两件独立素材，以及随前排商品归组的阴影。背景在图层清单内标为 `role: background`。

```json
{
  "objects": [["后排包装", "后排包装原件"], ["前排商品", "前排商品原件"]],
  "support": [["前排商品", "接触影"]],
  "reveal": [
    {"hide": [["前排商品"]], "rear": ["后排包装"], "roi": "原交叠位置:100,120,20,12", "min_percent": 40}
  ]
}
```

`objects` 列每个可单独编辑的素材名路径；组与其可移动影子一起关闭。独显目标为物体叶层。每层附有显示蒙版时，还要做停用蒙版的独显。可编辑文字的 `file` 指向原生文字层的独显 PNG。背景也要独显。有遮挡时，选定原来确实被遮住的区域，通过以下两次开关确认新显露的像素来自期望的物件。

1. 关闭 `hide` 中指定的前方物件，其余照常。
2. 保持相同状态，另外关闭 `rear`。脚本比较这两张图，同时检查全开时前景确实遮到了这个位置。`min_percent` 是核验框内显著改变的最低百分比；按实际几何选择。默认单通道可见差异阈值是 8，可用 `min_delta` 调整。

需要移动主要物件时，在验收表的根级加入 `"move":{"layer":["前排商品"],"dx":200,"dy":0}`，选择仍可在画内观察的整数位移。校样脚本会在副本中平移。查看移动后的轮廓与原来遮挡位置。

把物件清单和验收表写好以后，可以用同目录脚本生成逐件开关的 Photoshop 校样计划，减少手工列举路径。将生成的 JSON 放到图层清单旁边，再执行原生导出。在多次运行之间使用独立的工作目录，避免混入旧稿校样。

```sh
python3 scripts/plan_proof.py layers.json audit.json proof.json
python3 scripts/run_photoshop.py proof proof.json
```

使用没有前后遮挡的实物时，填 `"reveal":[]` 并在 `no_overlap_reason` 写明原因。透明小图可以直接作为一件完整素材。各文件路径按所属清单的位置解析。

```sh
python3 scripts/check_release.py source.png layers.json proof.json audit.json --json run-01.json
```

工具输出实际差异像素个数、PSD/输入/全开 PNG 的 SHA-256、物体开关和重叠区域结果。状态 0 表示自动检查通过，1 表示不合格，2 表示材料或输入有问题。仅支持当前装配器可读的 8 位 RGB/灰度 SDR JPG、PNG 源及 PSD 输出。在相同显示方向、像素大小、颜色编码下比较，JPEG 使用已解码像素，透明图比较所有 alpha 及可见处的 RGB。完全透明位置的隐藏 RGB 可不同。嵌入色彩空间不一致、特殊位深或 HDR 需另外验证。按双方可见像素并集计数，排除双方完全透明的位置。达到 99% 为二代，达到 95% 且低于 99% 为一代级，低于 95% 为待修。判定用整数交叉相乘，报告同时保留差异像素数。达到二代分数后仍需通过独立编辑核验。

自动检查读取真 PSD，核对素材、单独显示、关闭、蒙版停用和原遮挡处差异。对全不透明画面，还把 PSD 内的兼容合成预览与导出的全开 PNG 直接相减。校样应来自本次保存的 PSD；如怀疑配错，重开 PSD 并另存一套新校样。制作人仍须亲自看过每张单件、移位和遮挡后校样，核对真实材质、形体和视觉残影。脚本无法仅凭绝对坐标和数值辨认花纹、材质归属或原作隐藏的细节。
