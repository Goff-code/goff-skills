# 可见像素保留与误差复查

## 制作时先确定可见像素的归属

在原始画布上为每个编辑对象区分三种位置。

| 位置 | 取什么 | 关层检查 |
| --- | --- | --- |
| 原图中确实可见且不透明的部分 | 直接取对应源 RGB，保留相同采样格。木横档、杯口亮边和笔画都可能只有几像素宽。 | 隐藏相邻层后，细节仍跟着正确的物体。 |
| 被其他图层遮住的部分 | 原图提供两端的结构锚点。使用已对齐的生图补画，把蒙版收在遮挡区和必要的接缝。 | 临时移走前景，检查纹理方向与物体结构。 |
| 半透明边缘、相互透叠和投影 | 在对应物体或投影层内保留覆盖度。用邻近、同材质的底色估计边缘前景色。接影面单独保留纹理。 | 对象分别移到深浅两种底色；关闭投影时纹理还在，移动投影时无砖缝、字样或其他物件一起走。 |

底景可从全幅补画候选开始，把确认可见的原场景像素接回去。为此绘一张原位灰度蒙版，白色表示源像素确实归属此层，黑色代表遮挡、洞口或不确定处，灰色仅用于需要衔接的窄带。候选存在阴影时，先分离投影再用经过验证的接影面作源。主体层内被另一个物体挡住的地方必须从该主体的白区排除。

可对已对齐的 8 位原图与候选执行：

```text
<python> <skill>/scripts/restore_visible.py 原图.png 当前候选.png 可见归属蒙版.png 新版本图层.png
```

此操作保留候选原有 alpha，原图与候选均完全不透明时才采回源色。若生成抠件的整个实心内部被错误赋值为近白 alpha，先根据物体材质、离轮廓的距离、遮挡与细孔做独立校正。毛尖、玻璃和真实半透明层沿用各自的覆盖度。蒙版不能通过简单反转粗略外接框得到。

胡须、飞线等细节要沿实际笔迹提取。取线两侧同一表面的清底估计，恢复线条颜色及 alpha，然后清除底景中的同一根线。投在地面上的软影可结合原有砖缝或木纹反推衰减；交付时在图层组里只移动影子核看背景。全图指标提升但可移动物体出现第二圈轮廓时，返回检查底层残影与错层归属。

## 量化全开成果，抽查局部

使用原始输入和重开 PSD 后直接导出的 PNG，同尺寸、同显示方向、同颜色编码。一旦需要转换色域，先写明工作域和两边的转换方式。JPEG 输入比较其解码后的像素。全开预览使用 PNG，另行导出的 JPEG 仅供便览。单次基线里不要缩放、二次 JPEG 压缩或重新截图。

```text
<python> <skill>/scripts/check_fidelity.py 原图.png 校样/全开.png --min-exact 99 --roi "细线:720,595,100,85" --json 校样/保真报告.json
```

严格相同要求每个像素的 RGB 和有效 alpha 完全相同。全透明处的隐藏 RGB 不计；透明作品同步报告全画布及双方可见区域并集。ROI 按原画布的 x、y、宽、高指定。默认用于定位差异，如用户要求所有指定框分别达标，再加 `--enforce-roi`。观察局部细线、品牌字、细杆和孔洞时应同时看图：区域均值或通过率可能掩盖一根重要线条的缺失。

全图未过线时先收窄改写了露出底景的蒙版，再查实心主体的颜色和 alpha，最后查边缘及阴影。全图过线后仍须逐项关层并移动验收。保留原始输入、各版全开导出和实际报告，以便用户复核。

按物件选取细线、结构连接处和投影等高风险区域，对照原图、全开导出及关层校样。检查细节能否随所属物件移动，以及露出的背景能否连续衔接。
