# goff-image-99%

接到一张成图，交付一份改得动的源文件。判断分层是否合适，用设计师的下一步操作来衡量。例如，能否拿掉奶茶、换一行文案、单独移动一颗玛瑙，而且拿掉以后仍然有完整的台面、杯口或圆环。

**每个可交付素材都应完整。** 关闭任意前景后，后方物件须自然显露；把后方物件单独放到新底色上，也应具有符合视角的完整轮廓、结构和材质。把高遮挡对象与遮挡它的对象分组管理。先在原图圈出最容易被误删的交叠位置，参见 [完整素材与遮挡验收](references/whole-objects.md)。

**默认保真目标**为 PSD 全开、重开后导出的无损 PNG 与原图至少 **99% 可见像素严格相同**。同时通过元素隐藏、移动和关键细节目检。双方透明处忽略隐藏 RGB，含透明的作品还要单独达到可见区域门槛。用户指定其他数值时采用用户的数值。以实测结果报告达到的比例。

## 二代如何跑

把推理用于物件归属与遮挡，把计数、合成和误差定位交给脚本。适合从中等推理强度开始。工具不会更改所选模型或推理设置。

1. 从原图上确定可编辑物件及深度顺序，标出属于各物件的可见区域。先复用原图已露出的像素，只让内置生图补原图看不见的部分。完全规则的几何物体可以按原轨迹、颜色和笔宽补齐。
2. 完整物件按原坐标叠放、从磁盘重开 PSD 导出。用 `scripts/check_fidelity.py` 的差异图找出不同像素最集中的位置。优先修一个影响最大的归属问题，如桌布误占碗底，而后只重导受影响的核验图。最终验收重新导出全套校样。
3. 对有原始抗锯齿颜色的边缘，可按 [恢复可见边缘](references/edge-fit.md) 从实测承接底色估计前景像素。独显原件时留意桌布上是否出现碗底或原地面纹理。出现残影先减小采样范围并重判前后归属。
4. 将物件和需显露的部位写入验收表，用 `plan_proof.py` 生成开关清单。按 [二代验收](references/release-audit.md) 运行 `check_release.py`。全开相同像素至少占可见并集的 99%，主要素材的独显、隐藏、移位及露底均通过时停止。只差几个像素也照实报告。若在 95% 至不足 99% 之间，明确写“一代级，二代未达标”。发现可定位的归属错误就修对应对象；连续复测无有效改善或继续改会留下明显残影时，保留质量最好的一版，并报告欠缺部位。不要为了追满分整图重生或另加补差图层。
5. 可选记录每次生图、模型复审和 Photoshop 导出次数。记录可用于比较流程成本；报告 token 必须来自实际用量记录。

## 1. 先在原图上决定拆什么

读取原始文件并查看全图，再放大文字、交叠处和透明边缘。记录实际像素宽高、显示方向、原有透明度与裁边。以高分辨率原件为准。每张图建独立工作目录，新版本另存。

画一张简短的内部清单，每行写「元素｜想对它做什么｜它挡住谁／被谁挡住｜关掉后应该看见什么｜如何取得素材」。按以下问题删减清单。

- **会独立移动、替换或改字吗？** 主商品、可替换道具、标题、普通文案、独立遮挡商品的特效，通常值得拆。复杂海报可包含多个业务组；简单图片可以只有一两层。没有独立用途的背景纹理就留在背景。
- **哪些部件属于同一个编辑对象？** 桌椅、花瓶与桌面等仅因空间接触而相邻的物件分别建层，必要时在各自对象内再设子层。 包装印字和瓶身、礼盒和扎紧的蝴蝶结、倾倒壶与连续液流通常同组。成簇碎片、成对水果可合为一个素材。说明线和端点属于说明，接触阴影或投影归产生它的物体。投在另一可移动物体上的影，单独裁到接影面，并测试两者的开关组合。
- **哪里需要补成完整物体？** 沿每条遮挡关系逐级确认后方对象及其底面。先补后方的完整几何，再把前景叠回去。珠宝孔洞应透出下层；杯口应在液流移走后接成椭圆；跨越物体前后的特效可用前后两个子层配合同一命名或链接；关掉主体时应能看到整个特效。对画面边缘已经裁断的主体沿用原裁切，用户要求扩图时再补出画外部分。
- **哪类字能真正编辑？** 海报普通文案逐字校对后重建为 Photoshop 文字层，以编辑动作分组。书法、字标和包装印刷优先保留原字形；用户要求单改包装印字时，另提印字并补净包装表面。看不清的字保留可见像素，标注需原稿确认的部分。

在原图透明的作品中保留空背景和原有开孔。需要独立场景时才重建完整背景。一般可直接根据清单执行；新增文案、改变商品身份或猜测关键商标会影响交付时，先用可确认的信息完成其余工作。

## 2. 从原像素提取，用内置生图补遮挡

按元素选择成本最低且保真的方法。

| 画面情况 | 制作办法 |
| --- | --- |
| 可见的照片主体、清晰的书法、完整图形 | 原图蒙版或色彩选取，保留纹理、字形和轮廓；有空洞就抠出内轮廓。 |
| 简单曲线、几何边界、指示线与圆点 | 按原坐标重建路径或形状。移除它们在底层留下的痕迹。 |
| 被遮住的桌面、石纹、布褶、产品局部 | 使用当前会话的 **Codex 内置图像生成／编辑工具**。用原图为参考，按目标分别生成完整底景或单个对象的缺失部分。工具可用时直接调用，无须外部模型、API 密钥或其他 Skill。 |
| 半透明玻璃、烟雾、发丝、柔影与光晕 | 保留连续 alpha 和反光；在深浅两种底色上看边缘。单张图难以反推原始透明度时，保留相互依赖的部分为一组，说明适用底色或换底局限。 |
| 人脸、品牌、包装配方、标记、二维码等身份细节 | 复用清晰原像素或用户的源素材。推测只用于接续非关键材质。无法确认的隐藏身份或文字不当作还原成果。要求可扫码时另做真实解码验证。 |

为每个生成目标单独描述保留项、移除项、遮挡后应显露的结构及定位锚点。背景用原构图和场景光向；抠件请求真实透明。写法及题材示例见 [补全提示词](references/prompts.md)。保存实际提交的提示词和工具返回的原始图像到本次工作目录。若返回的是图像数据，在工具上下文中将其写成文件，勿把编码串打印进对话。

生成结果只是补画候选。根据画布尺寸、两个以上可见锚点、边缘走向对齐回原图，只在需要补的区域和接缝使用。原本清楚的包装字、纹理和商品轮廓优先来自原图。检查缩放后的细纹和噪点是否接得上；看得出补丁就缩小蒙版范围或重做。生成工具不可用时继续做可确定的蒙版、文字与几何重建，把需生图且未完成的区域标明。

在组装前按归属保护可见原像素。底层保留原图上可确认的露出表面，补画限制在遮挡及必要接缝内。商品、人物等实心部分直接用原 RGB，剪影外的胡须、细线、叶梗和透孔逐项检查。把影子从它所在的地面或墙面分离，移动时保留接影面的纹理。相关蒙版做法及可复用工具见 [可见像素保留与误差复查](references/fidelity.md)。

## 3. 组装并实际关层验收

1. 保持原画布坐标。前景使用真正的 alpha，全画布导出后可直接叠齐；效果、投影保留柔边。原图仅供比对，默认可见层里不要垫回整张海报。
2. 建立从底到顶的图层清单。使用本机可用的 Photoshop 或能保留所需编辑性的工具。配套脚本可将完整 PNG、独立灰度蒙版、可编辑文字和嵌套组装成 PSD。需要修边的素材保留原件，并用链接的 Photoshop 像素蒙版保留可修改的笔画。普通前后遮挡由图层顺序产生，藏在后面的部分随前景的开关自然显露。命令、兼容范围和最小清单见 [组装与核验](references/assembly.md)。
3. **从磁盘重开 PSD**。核对像素尺寸、组内外上下关系、文字层类型和实际内容。导出全开 PNG，对这份真实导出运行 `scripts/check_fidelity.py`，记录严格相同的像素数、比例以及超差最集中的区域。查看全图并在原始尺度对照关键的字形、五官、轮廓附件、交叠结构、投影和透孔。若环境只能读文件结构，要明确此次验证的范围。
4. **每件独立素材分别单看、关掉。** 对照清单逐层检查，包含组内可单独操作的对象。先导出可能出错的前后组合，再把后方物体也关闭，在原遮挡区核实究竟是哪一层提供了椅面、杯沿或布纹。测试副本中移动一次主要遮挡者，检查原位置和新位置。对带蒙版的关键对象再导出一次停用蒙版的独立全件，在深浅底复核孔洞、边缘与纹理。最后关闭所有前景看纯底图。
5. 比例未达标或关键细节缺失时，定位到具体图层与遮挡对，优先修归属和蒙版，再组装、重开、复查。禁止在成稿中垫完整原图、叠整幅差值或把前景残像藏在底景。若仍未达标，列出未过项目及实际测值，标为待修。全开相似度和物件完整性分别验收。技术脚本通过后仍须看每种开关状态的实际画面。

默认交分层 PSD、原位 PNG 素材包、用于计算保真率的全开 PNG，以及一张展示「全开／关键前景关闭后露出的物体／物体单独显示」的对照图，并附独立的空背景校样。交客户的预览用已保存的 PSD 重开后直接无损导出。原始透明作品可用棋盘格展示对照，导出的素材保持真透明。附本次实际拆层和补图提示词，说明可编辑文字、依原图保留的部分、重建部位及仍存在的局限。遵循用户对格式或范围的单次要求。
