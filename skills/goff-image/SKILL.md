# Goff Image

输入一张 JPG 或 PNG，交付可继续在 Photoshop 编辑的源文件。两代都要求能独立取出完整物件，关掉前景时自然显露后面的内容。

| 调用 | 合成验收 |
| --- | --- |
| `$goff-image-1` | 原尺寸的全开无损导出须与原图至少 95% 的像素严格相同。 |
| `$goff-image-2` | 原尺寸的全开无损导出须与原图至少 99% 有效像素严格相同，同时通过素材完整性检查。 |

用户在本菜单明确提出“一代”“二代”、对应编号或点名具体入口时，保留用户已给的图片和任务，读取并执行已选代际的 SKILL.md。按所选技能的安装目录定位配套脚本。用户只打开菜单时，展示两项并等待选择。用户只咨询能力时，说明对应验收条件。未安装所选代际时提示安装其具体入口。

每次报告当前作品与原图的实测值。用户查看的 PSD 和预览应源自同一份交付文件。
